# Prism — AI 美甲试戴与智能运营平台

> 美团黑客马拉松 2026 · 一键试戴 + 趋势发现 + AI 微调

## 核心功能

### 用户端 — AI 试戴与款式浏览
- **AI 虚拟试戴**：上传手图，AI 自动识别指甲区域，将款式实时渲染到手指上
- **款式库浏览**：按风格、色系、甲型等多维标签筛选美甲款式
- **AI 对话推荐**：自然语言描述需求，AI 助手智能推荐匹配款式
- **单指微调**：选中任意手指，独立调整颜色、法式纹样或添加装饰品

### 商户端 — 智能运营平台
- **趋势发现 Agent**：从小红书等 UGC 平台自动抓取帖子 → 清洗 → 评论抓取 → AI 趋势识别，输出趋势池
- **爆款推送**：趋势一键转为推送卡片，支持合成图生成、推荐语自动撰写、优惠券绑定
- **数据看板**：试戴转化漏斗、热度趋势、AI 运营播报
- **投流管理**：预算分配与 ROI 追踪

## 技术亮点

| 能力 | 实现 |
|------|------|
| 指甲区域识别 | 多模态 VL 模型精确定位 5 指四点坐标（归一化），支持手图和款式图 |
| AI 图像生成 | GPT Image API 驱动，支持整体甲型变换、换色、单指微调 |
| 趋势识别管道 | UGC 导入 → 帖子分类 → 评论摘要 → 多信号交叉验证 → 趋势打分 |
| 合成图生成 | 款式图 + 裸手模板 → AI 合成爆款推送预览图 |
| 智能标签体系 | 12 维度美甲标签分类（风格/色系/甲型/场景/季节等） |

## 项目结构

```
├── backend/          # FastAPI 后端
│   ├── app/api/      # 17 个 API 模块
│   ├── app/services/ # 业务逻辑（图像生成、趋势分析、微调等）
│   └── storage/      # SQLite + 生成图 + 参考素材
├── frontend/         # 原生 HTML/JS/CSS 前端
│   ├── user/         # 用户端（试戴、款式浏览）
│   └── admin/        # 商户运营端（趋势发现、推送管理）
└── .env              # API Key 等环境变量
```

## 快速启动

```bash
# 后端
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# 前端
cd frontend
npx vite --port 5173
```

访问 `http://localhost:5173`（用户端）/ `http://localhost:5173/admin/`（商户端）。
