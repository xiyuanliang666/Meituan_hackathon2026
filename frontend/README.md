# 美甲AI智能运营 - 前端代码

## 项目结构

```
前端代码/
├── index.html              # 总入口（导航到用户端/运营端）
├── README.md
├── user/                   # 用户端（C端 - 移动端）
│   ├── index.html
│   ├── styles.css
│   └── app.js
└── admin/                  # 运营端（B端 - PC端）
    ├── index.html
    ├── admin-styles.css
    └── admin-app.js
```

## 使用方式

直接浏览器打开 `index.html`，选择进入用户端或运营端。

## 改进要点（相对原型）

1. **统一SPA架构** — 原型是6个独立HTML，优化为Tab切换的单页应用
2. **导航优化** — 顶部Tab导航替代面包屑，页面切换更流畅
3. **视觉统一** — 统一圆角、间距、颜色系统，提升整体品质感
4. **交互增强** — 卡片hover效果、模态弹窗、状态动画
5. **响应式** — 适配移动端和PC端
6. **用户端新增** — 完整的C端用户页面体系（原型中没有）
